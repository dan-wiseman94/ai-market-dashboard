## F3 COVERAGE — full plan (the remaining unit)

**Goal / thesis.** Fix the "amnesiac-by-snapshot" core limitation: each watchlist
name gets a single, persistent, version-controlled "house view" the AI **revises
with a reason** (behind a hysteresis gate) instead of re-deriving each snapshot.
Effort: **L** (new app + AI pipeline + frontend).

### Backend

**New app `apps/coverage`** (use the `new-django-app` skill, or mirror `apps/lessons`).
Wire: `INSTALLED_APPS`, `config/urls.py` (`path("api/coverage/", ...)` BEFORE the
generic `/api/`), and — if you add a task module — `config/celery.py`
`autodiscover_tasks([...])`.

**Models** (`apps/coverage/models.py`):
- `CoverageNote` — `ticker` (CharField, unique), `stance`
  (`bull`/`bear`/`neutral` choices), `conviction` (PositiveSmallInt 1-5),
  `bull_case` (TextField), `bear_case` (TextField), `key_levels` (JSONField,
  default dict), `watching_for` (TextField), `updated_at` (auto_now),
  `created_at`.
- `CoverageRevision` (append-only history) — `note` FK→CoverageNote
  (related_name="revisions"), `prior` (JSONField — snapshot of the note before),
  `new` (JSONField — the revised note), `reason` (TextField),
  `source_snapshot` FK→`snapshots.Snapshot` (null=True, SET_NULL),
  `created_at`. `Meta.ordering = ["-created_at"]`.
- Migration is plain `CreateModel` (no pgvector). **Ruff-format generated
  migrations** (single→double quotes) before committing.

**Revision schema** (`apps/coverage/schemas.py`) — a Pydantic model for
`run_structured`, mirroring `apps/observer/schemas.py::ObservationReport`:
```python
class CoverageRevisionDraft(BaseModel):
    material_change: bool          # the hysteresis gate — did anything earn a revision?
    stance: Literal["bull", "bear", "neutral"]
    conviction: int = Field(ge=1, le=5)
    bull_case: str
    bear_case: str
    key_levels: dict = Field(default_factory=dict)
    watching_for: str
    reason: str                    # WHY the view changed (or was reaffirmed)
```

**Service** (`apps/coverage/services/revise.py`) — `revise_coverage(ticker, snapshot, *, profile)`:
1. `note, _ = CoverageNote.objects.get_or_create(ticker=ticker.upper(), defaults=...)`.
2. Build the user prompt: the **prior note** (serialized) + the situation —
   prefer the **diff** vs the prior snapshot (`apps/snapshots/diff.diff_sections`
   + `apps/snapshots/primary.previous_snapshot_for`), else
   `serialize_for_ai(snapshot, provider=, model=)`.
3. Resolve provider/model + key from `ProviderConfig` (mirror
   `apps/observer/services/run.py::_run_structured_and_record`); cap-check
   (`check_daily_cap`/`check_monthly_cap`) before the call.
4. `draft = run_structured(api_key=, model=, system=build_system_prompt(profile, now=...),
   user=<prompt>, output_model=CoverageRevisionDraft, base_url=)`.
   **`run_structured` has NO `MOCK_EXTERNAL` short-circuit — tests MUST patch it.**
5. **Hysteresis gate:** only persist a `CoverageRevision` + update the
   `CoverageNote` when `draft.material_change` is True (and/or stance/conviction
   actually changed). Otherwise just touch `updated_at` (reaffirm, no churn row).
6. Best-effort / cap-aware / `contextlib.suppress` around the AI call so a fire is
   never broken by a revision failure (mirror `_extract_prediction`).

**Observer hook** — in `apps/observer/services/run.py`, after a plain fire on a
ticker that has a `CoverageNote`, dispatch a cap-gated task
`coverage.revise_from_observation` (new module → add to `autodiscover_tasks`).
Auto-covers names you've started covering. Keep it opt-in/safe.

**API** (`apps/coverage/views.py` + `urls.py`):
- `GET /api/coverage/` — list notes (latest).
- `GET /api/coverage/<ticker>/` — the note + its revisions (the history).
- `POST /api/coverage/<ticker>/revise/` — manual trigger (captures a fresh
  snapshot or uses the latest, then `revise_coverage`).
Use DRF `APIView` (mirror `apps/analytics/views.py`) or a `ViewSet`; serializers
need `ClassVar` on `Meta.fields` (ruff RUF012).

**Tests** (`apps/coverage/tests/`): patch `run_structured` to return a
`CoverageRevisionDraft`; assert (a) material_change=True → a `CoverageRevision`
created + note updated; (b) material_change=False → no revision row (reaffirm);
(c) get-or-create on first sight; (d) endpoint shapes. Mirror the fixture style in
`apps/observer/tests/test_structured_outputs.py`.
