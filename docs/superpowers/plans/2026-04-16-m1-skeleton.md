# M1 Skeleton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A `docker compose up` that boots the entire stack — Django (ASGI) + Channels + Celery worker + Celery beat + Redis + Postgres + React (Vite) — with a live `/api/health` endpoint, a functioning WebSocket smoke echo, and a Celery ping task that round-trips through Redis. This is the foundation every later milestone builds on.

**Architecture:** Per `docs/superpowers/specs/2026-04-16-ai-dashboard-design.md` §2–§3. Django 5 project named `config`, apps under `backend/apps/`, Channels routing through Daphne, Celery app `config.celery`, React 18 + Vite 5 under `frontend/`. Prod serves the built frontend through Whitenoise on the `web` container; dev runs Vite in a sidecar container.

**Tech Stack:** Python 3.12, Django 5.1, DRF 3.15, Channels 4.1, Celery 5.4, Redis 7, Postgres 16, `uv` for Python packaging, Node 20, React 18, Vite 5, TypeScript 5, Tailwind 3, shadcn/ui, `pytest` + `pytest-django` + `channels` testing + `fakeredis`, `vitest` + `@testing-library/react`, ruff + mypy, structlog.

Responsibilities:

- **`config/`** — Django project (settings, asgi/wsgi, celery, root urls, channels routing). No domain logic.
- **`apps/core/`** — health & readiness endpoints, the one smoke-test WebSocket consumer, the one `ping` Celery task, base logging setup. Everything else belongs to future apps.
- **`frontend/src/api/`** — HTTP client only.
- **`frontend/src/hooks/`** — React hooks that talk to the API or WS.
- **`frontend/src/App.tsx`** — single shell with "Stack is green" when `/api/health` reports all deps up.

"""Health and readiness endpoints."""
from __future__ import annotations

import redis
from django.db import connection
from django.http import HttpRequest, JsonResponse
from django.views.decorators.http import require_GET

from django.conf import settings


@require_GET
def health(_request: HttpRequest) -> JsonResponse:
    """Liveness: always 200 if the process is up."""
    return JsonResponse({"status": "ok"})


@require_GET
def ready(_request: HttpRequest) -> JsonResponse:
    """Readiness: per-dependency health."""
    db_status = _check_database()
    redis_status = _check_redis()
    overall_ok = db_status == "ok" and redis_status == "ok"
    status_code = 200 if overall_ok else 503
    return JsonResponse(
        {"database": db_status, "redis": redis_status},
        status=status_code,
    )


def _check_database() -> str:
    try:
        with connection.cursor() as cursor:
            cursor.execute("SELECT 1")
            cursor.fetchone()
        return "ok"
    except Exception:
        return "error"


def _check_redis() -> str:
    try:
        client = redis.Redis.from_url(settings.REDIS_URL, socket_connect_timeout=1)
        client.ping()
        return "ok"
    except Exception:
        return "error"

```ts
import { useEffect, useState } from "react";
import { fetchHealth } from "@/api/client";

export type HealthState = "loading" | "ok" | "down";

export function useHealth(): HealthState {
  const [state, setState] = useState<HealthState>("loading");

  useEffect(() => {
    let cancelled = false;
    fetchHealth()
      .then((body) => {
        if (!cancelled) setState(body.status === "ok" ? "ok" : "down");
      })
      .catch(() => {
        if (!cancelled) setState("down");
      });
    return () => {
      cancelled = true;
    };
  }, []);

  return state;
}
```
